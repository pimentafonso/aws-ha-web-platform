Notes API

A small API used to exercise a highly available AWS platform: CloudFront and WAF in front of an Application Load Balancer, ECS Fargate across two Availability Zones, RDS PostgreSQL Multi-AZ and ElastiCache for Valkey. This page is served from S3 through CloudFront; the API paths go to the load balancer.

GET /healthLiveness
GET /readyDatabase and cache checks
POST /api/notesCreate a note: {"title": "...", "content": "..."}
GET /api/notesList recent notes
GET /api/notes/:idRead a note (X-Cache shows HIT or MISS)
DELETE /api/notes/:idDelete a note
